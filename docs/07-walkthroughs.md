## תרחיש 3 — סיכום שבועי (יום חמישי 16:00)

```
[טריגר]  ה-scheduler יורה digest.weekly לפי charter.operations.workweek ואזור הזמן
         **לא מקודד קשיח ליום שישי** — שבוע העבודה של עסק ישראלי נגמר בחמישי

[הרכבת עובדות]  קוד ה-ORCHESTRATOR. בלי LLM. כ-12 שאילתות SQL מקבילות:
  unanswered_threads          (L3 + L5: נכנס בלי תשובה יוצאת, גיל > SLA)
  approvals_pending / expired (L5)
  followups_overdue           (L5, state='open' AND dueAt < now)
  actions_taken_by_class      (L2, מקובץ, עם ספירות וסכומי כסף)
  money_spent_vs_budget       (L2 + תקרות התקנון)
  calendar_next_week          (MCP יומן, קריאה בלבד)
  crm_pipeline_delta          (Zapier MCP, קריאה בלבד)
  anomalies_detected          (NormsEngine, z > 3 השבוע)
  preferences_promoted        (מעברי סטטוס ב-L4)
  charter_amendment_proposals (מכריית עקיפות ודחיות)
  incidents / kill_switch_events (L2)
  cost_this_week              (חשבונאות טוקנים וכסף ב-L2)
  → PeriodFacts { כל ערך נושא factId ושאילתת drill-down }

[רינדור]  know.digest (Sonnet 5) — מקבל PeriodFacts, **בלי שום כלי תשאול**
  סדר עדיפות קבוע (תשומת הלב של הבוס היא המשאב הנדיר במערכת):
    1. צריך את ההחלטה שלך      — אישורים ממתינים ושפגו
    2. בסיכון                    — מעקבים באיחור, לקוחות ללא מענה
    3. כסף                       — הוצאה מול תקציב, סכומים חריגים, פערי חשבוניות
    4. השבוע הבא                 — יומן, התחייבויות שמגיע מועדן
    5. מה עשיתי בשבילך           — פעולות שבוצעו, מקובצות, עם ספירות
    6. מה למדתי / מה אני מציעה לשנות — קידומי העדפות + תיקוני תקנון
  כל שורה נושאת את ה-factIds שלה כדי שהדשבורד יוכל לצלול פנימה

[verify]  דטרמיניסטי, אפס עלות מודל:
  חילוץ כל מספר מהתדריך המרונדר
  אימות שכל אחד ∈ ערכי PeriodFacts (עד עיגול)
  כל מספר ללא מקור → **חסימת המסירה** והתרעה להנדסה
  ⭐ הבדיקה האחת הזו תופסת את מצב הכשל ההרסני ביותר של סוכן מסכם:
     מספר סביר שאף אחד לא הזין

[מסירה]
  מייל: התדריך המלא, HTML, עם קישורי drill-down
  WhatsApp: גרסת 5 שורות + "3 החלטות ממתינות" + קישור
  דשבורד: מארכב, ניתן להשוואה שבוע מול שבוע

[remember]  התדריך מארכב כמסמך. האינטראקציה של הבוס איתו — אילו פריטים
            הוא פותח, על אילו הוא פועל — נרשמת ומזינה מודל רלוונטיות
            שמסדר מחדש את סעיף 5 לאורך זמן

[update]  ⭐ זהו טקס הממשל. הצעות תיקון התקנון שעולות כאן הן המסלול העיקרי
          שבו התקנון נשאר עדכני — כי הן מגיעות בתוצר האחד שבעל העסק
          קורא באופן אמין
```

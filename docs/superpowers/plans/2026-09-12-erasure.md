# Erasure on the Owner's Command — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The owner names something to forget — a contact, a time window, or a document — and after they confirm a preview, it is deleted from every place that holds content, permanently.

**Architecture:** A pure resolver turns an anchor into an `ErasurePlan` (counts, ids, exclusions, refusals) without touching anything. A separate executor deletes exactly what the plan lists, in one transaction, then unlinks files, then writes a count-only audit row. A dashboard screen shows the plan and takes the confirmation. Erasure is never a tool: no agent allowlist names it and no plan can call it.

**Tech Stack:** TypeScript NodeNext ESM (`.js` on every relative import), Postgres 17 via `pg`, zod, vitest against a real database.

**Spec:** `docs/superpowers/specs/2026-09-12-erasure-design.md`

## Global Constraints

- **`.js` on every relative import**, including from `.ts` files. Required by `NodeNext` + `"type": "module"`.
- **Three tsconfig flags bite:** `noUncheckedIndexedAccess` (forces `rows[0]?.x`), `exactOptionalPropertyTypes` (forces conditional spread: `x !== undefined ? { x } : {}`), `verbatimModuleSyntax` (forces `import type` for types).
- **Tests need a real Postgres.** No mocks, no in-memory DB. `npm run migrate:test` after adding a migration.
- **Hebrew for humans, English for code.** Rejection messages, screen copy and docs in Hebrew; identifiers, comments and internal errors in English.
- **Erasure is never a tool.** Nothing added to `TOOL_ACTION_CLASS`, `READ_ONLY_TOOLS`, or any `AGENT_ALLOWLISTS` entry.
- **Positive controls.** A control is written as "these are permitted", never "everything except X".
- **A row per module that reads DB rows:** a private `interface XRow` plus a `toX(row)` function. SQL in `snake_case`, TS in `camelCase`.
- **Every new table must be added to the `TRUNCATE` list in `src/test/db.ts`** — `memories` had to be added by hand because its job reference is deliberately not a foreign key, and the same applies here.
- **Commit after every task.** Run `npm run typecheck && npm test` before each commit.

-- 025_kept_items.sql
--
-- What the owner said to keep.
--
-- One table rather than a `kept_at` column on documents, memories and jobs.
-- The question "what am I keeping?" has to be answerable in one query, the
-- revoke button has to write in one place, and adding a fourth keepable kind
-- must not mean a fourth migration altering a fourth table.
--
-- Keeping is permanent until revoked, and it never hides: every erasure
-- preview lists what it is skipping and why (spec §6).

CREATE TABLE kept_items (
    business_id TEXT        NOT NULL,
    -- Closed at the database. A fourth kind is a migration and a decision,
    -- never a value that arrives at runtime.
    item_kind   TEXT        NOT NULL CHECK (item_kind IN ('document', 'memory', 'job')),
    item_id     TEXT        NOT NULL,
    kept_at     TIMESTAMPTZ NOT NULL DEFAULT now(),
    -- Why the owner kept it, in their words. Optional: the act is the point.
    note        TEXT,

    PRIMARY KEY (business_id, item_kind, item_id),

    CONSTRAINT kept_items_id_not_empty CHECK (length(btrim(item_id)) > 0),
    CONSTRAINT kept_items_note_bounded CHECK (note IS NULL OR length(note) <= 500)
);

CREATE INDEX kept_items_business_idx ON kept_items (business_id, kept_at DESC);
```

/**
 * What the owner said to keep.
 *
 * Erasure removes everything an anchor reaches; this is the one list that
 * survives it. A kept item is never skipped silently — `buildErasurePlan`
 * carries it into the preview as an exclusion with the date it was kept, and
 * the screen offers to revoke it in one click (spec §6). A deletion that
 * quietly passed over things would be the same silent half-truth this
 * codebase keeps stamping out elsewhere.
 */
import { config } from '../config.js';
import { getPool, type Queryable } from '../db/pool.js';

/** Closed here and closed again by a CHECK in migration 025. */
export type KeptItemKind = 'document' | 'memory' | 'job';

export interface KeptItem {
  kind: KeptItemKind;
  itemId: string;
  keptAt: Date;
  note: string | null;
}

interface KeptRow {
  item_kind: string;
  item_id: string;
  kept_at: Date;
  note: string | null;
}

function toKeptItem(row: KeptRow): KeptItem {
  return {
    kind: row.item_kind as KeptItemKind,
    itemId: row.item_id,
    keptAt: row.kept_at,
    note: row.note,
  };
}

export async function keepItem(
  input: { kind: KeptItemKind; itemId: string; note?: string },
  options: { businessId?: string; db?: Queryable } = {},
): Promise<void> {
  const db = options.db ?? getPool();
  await db.query(
    `INSERT INTO kept_items (business_id, item_kind, item_id, note)
     VALUES ($1, $2, $3, $4)
     ON CONFLICT (business_id, item_kind, item_id)
     DO UPDATE SET note = EXCLUDED.note, kept_at = now()`,
    [options.businessId ?? config.businessId, input.kind, input.itemId, input.note ?? null],
  );
}

/** Returns how many rows it touched, so nothing can report success over zero. */
export async function revokeKeep(
  kind: KeptItemKind,
  itemId: string,
  options: { businessId?: string; db?: Queryable } = {},
): Promise<number> {
  const db = options.db ?? getPool();
  const result = await db.query(
    'DELETE FROM kept_items WHERE business_id = $1 AND item_kind = $2 AND item_id = $3',
    [options.businessId ?? config.businessId, kind, itemId],
  );
  return result.rowCount ?? 0;
}

export async function listKept(
  options: { businessId?: string; db?: Queryable } = {},
): Promise<KeptItem[]> {
  const db = options.db ?? getPool();
  const { rows } = await db.query<KeptRow>(
    `SELECT item_kind, item_id, kept_at, note FROM kept_items
      WHERE business_id = $1 ORDER BY kept_at DESC`,
    [options.businessId ?? config.businessId],
  );
  return rows.map(toKeptItem);
}

/** The ids of one kind, as a set the resolver can test membership against. */
export async function keptIds(
  kind: KeptItemKind,
  options: { businessId?: string; db?: Queryable } = {},
): Promise<Set<string>> {
  const db = options.db ?? getPool();
  const { rows } = await db.query<{ item_id: string }>(
    'SELECT item_id FROM kept_items WHERE business_id = $1 AND item_kind = $2',
    [options.businessId ?? config.businessId, kind],
  );
  return new Set(rows.map((row) => row.item_id));
}
```

```ts
/**
 * Deciding that a typed instruction is a forget command — and nothing more.
 *
 * This routes; it never decides what is deleted. The owner's text opens the
 * erasure screen pre-filled with whatever can be read out of it with
 * certainty, and everything else is picked from a list of things that really
 * exist (spec §4.1). A model is deliberately not used: classification would
 * make "which screen did my instruction go to" a probabilistic question, and
 * the answer has to be inspectable.
 *
 * The verb must OPEN the text. A supplier's sentence can reach the
 * instruction box by paste, and a verb matched anywhere would make quoting
 * someone a way to trigger the screen.
 */

/** The openings that mean "forget". A positive list, matched at the start. */
const FORGET_VERBS: readonly string[] = ['תשכחי', 'שכחי', 'תמחקי', 'מחקי'];

/**
 * Same shape as `typed-recipients.ts` uses: a whole-token test, not a scan
 * for something address-like inside a longer run of characters.
 */
const EMAIL_SHAPE = /^[^\s@]+@[^\s@.]+(?:\.[^\s@.]+)+$/;

/** `3/9/2026`, `03.09.2026`, `3-9-26` — day first, as Hebrew writes it. */
const DATE_SHAPE = /^(\d{1,2})[./-](\d{1,2})[./-](\d{2,4})$/;

export type ForgetCommand =
  | { recognised: false }
  | { recognised: true; identifier: string | null; onDate: string | null };

/** Strips the Hebrew prefix particles and punctuation a token may carry. */
function bareToken(token: string): string {
  const withoutPrefix = /^[לבמהוכש]-/.test(token) ? token.slice(2) : token;
  return withoutPrefix.replace(/^[('"«]+/, '').replace(/[)'"»,.;:!?]+$/, '');
}

function readDate(token: string): string | null {
  const match = DATE_SHAPE.exec(token);
  if (match === null) return null;
  const [, dayRaw, monthRaw, yearRaw] = match;
  if (dayRaw === undefined || monthRaw === undefined || yearRaw === undefined) return null;

  const day = Number(dayRaw);
  const month = Number(monthRaw);
  const year = yearRaw.length === 2 ? 2000 + Number(yearRaw) : Number(yearRaw);
  if (day < 1 || day > 31 || month < 1 || month > 12) return null;

  return `${String(year).padStart(4, '0')}-${String(month).padStart(2, '0')}-${String(day).padStart(2, '0')}`;
}

export function readForgetCommand(text: string): ForgetCommand {
  const trimmed = text.trim();
  const firstToken = bareToken(trimmed.split(/\s+/)[0] ?? '');
  if (!FORGET_VERBS.includes(firstToken)) return { recognised: false };

  let identifier: string | null = null;
  let onDate: string | null = null;

  for (const raw of trimmed.split(/[\s ]+/)) {
    const token = bareToken(raw);
    if (identifier === null && EMAIL_SHAPE.test(token)) {
      identifier = token.toLowerCase();
      continue;
    }
    if (onDate === null) {
      const date = readDate(token);
      if (date !== null) onDate = date;
    }
  }

  return { recognised: true, identifier, onDate };
}
```

  anchor: ErasureAnchor;
  jobIds: string[];
  documentIds: string[];

/**
 * Turning "forget this" into exactly what will be deleted.
 *
 * Read-only, and that is the boundary that matters: `executeErasure` deletes
 * precisely what this returns and resolves nothing of its own. Anything this
 * function misses is not deleted, and anything it lists is shown to the owner
 * before a row is touched — which is what makes the preview the truth rather
 * than a decoration (spec §4.4).
 *
 * The anchor is searched in seven places (spec §4.3), and every match closes
 * over to the job or document that carries it, so dependent rows — readings,
 * proposals, extracted parts, step records — come along.
 */
import { config } from '../config.js';
import { getPool, type Queryable } from '../db/pool.js';
import { keptIds, type KeptItemKind } from './kept-items.js';

export type ErasureAnchor =
  | { kind: 'contact'; identifier: string }
  | { kind: 'window'; fromIso: string; toIso: string }
  | { kind: 'document'; documentId: string };

export interface ErasureItem {
  table: string;
  action: 'delete' | 'scrub';
  count: number;
}

export interface ErasureRefusal {
  kind: 'live_job' | 'signed_document';
  detail: string;
}

export interface KeptExclusion {
  itemKind: KeptItemKind;
  itemId: string;
  keptAt: string;
  note: string | null;
}

export interface ErasurePlan {
  anchor: ErasureAnchor;
  jobIds: string[];
  documentIds: string[];
  memoryIds: string[];
  filePaths: string[];
  items: ErasureItem[];
  excluded: KeptExclusion[];
  refusals: ErasureRefusal[];
}

/**
 * A phase the owner is still involved in, or the engine is mid-way through.
 * Erasing under one of these leaves a job pointing at a plan that no longer
 * exists (spec §7.1).
 */
const LIVE_PHASES: readonly string[] = ['execute', 'await_approval'];

/**
 * Escapes what `LIKE` would otherwise read as a pattern.
 *
 * The anchor is owner-supplied text. A bare `%` would match every row in
 * every table searched — the same reason `recallMemories` escapes its
 * keyword.
 */
function likeLiteral(value: string): string {
  return value.replace(/[\\%_]/g, (ch) => `\\${ch}`);
}

async function idsFrom(
  db: Queryable,
  sql: string,
  params: unknown[],
  column: string,
): Promise<string[]> {
  const { rows } = await db.query<Record<string, string>>(sql, params);
  return rows.map((row) => row[column] as string);
}

export async function buildErasurePlan(
  anchor: ErasureAnchor,
  options: { businessId?: string; db?: Queryable } = {},
): Promise<ErasurePlan> {
  const businessId = options.businessId ?? config.businessId;
  const db = options.db ?? getPool();

  const jobIds = new Set<string>();
  const documentIds = new Set<string>();

  if (anchor.kind === 'contact') {
    const pattern = `%${likeLiteral(anchor.identifier)}%`;
    const exact = anchor.identifier;

    for (const jobId of await idsFrom(
      db,
      `SELECT DISTINCT job_id FROM job_authorizations
        WHERE business_id = $1 AND $2 = ANY (recipients)`,
      [businessId, exact],
      'job_id',
    )) jobIds.add(jobId);

    for (const jobId of await idsFrom(
      db,
      `SELECT DISTINCT job_id FROM job_plans
        WHERE business_id = $1 AND plan::text ILIKE $2 ESCAPE '\\'`,
      [businessId, pattern],
      'job_id',
    )) jobIds.add(jobId);

    for (const jobId of await idsFrom(
      db,
      `SELECT DISTINCT job_id FROM boss_instructions
        WHERE business_id = $1
          AND (text ILIKE $2 ESCAPE '\\' OR coalesce(answer, '') ILIKE $2 ESCAPE '\\')`,
      [businessId, pattern],
      'job_id',
    )) jobIds.add(jobId);

    for (const jobId of await idsFrom(
      db,
      `SELECT DISTINCT job_id FROM approval_requests
        WHERE business_id = $1 AND job_id IS NOT NULL
          AND (coalesce(proposed_input::text, '') ILIKE $2 ESCAPE '\\'
            OR coalesce(edited_input::text, '')  ILIKE $2 ESCAPE '\\'
            OR summary ILIKE $2 ESCAPE '\\'
            OR detail  ILIKE $2 ESCAPE '\\')`,
      [businessId, pattern],
      'job_id',
    )) jobIds.add(jobId);

    for (const jobId of await idsFrom(
      db,
      `SELECT job_id FROM jobs WHERE business_id = $1 AND coalesce(title, '') ILIKE $2 ESCAPE '\\'`,
      [businessId, pattern],
      'job_id',
    )) jobIds.add(jobId);
  }

  if (anchor.kind === 'window') {
    for (const jobId of await idsFrom(
      db,
      `SELECT job_id FROM jobs WHERE business_id = $1 AND created_at >= $2 AND created_at < $3`,
      [businessId, anchor.fromIso, anchor.toIso],
      'job_id',
    )) jobIds.add(jobId);
  }

  if (anchor.kind === 'document') {
    documentIds.add(anchor.documentId);
  }

  // Documents reached through the jobs that read them.
  if (jobIds.size > 0) {
    for (const documentId of await idsFrom(
      db,
      `SELECT DISTINCT d.document_id FROM documents d
         JOIN document_readings r ON r.document_id = d.document_id
         JOIN proposals p ON p.reading_id = r.reading_id
        WHERE d.business_id = $1 AND p.job_id = ANY ($2)`,
      [businessId, [...jobIds]],
      'document_id',
    )) documentIds.add(documentId);
  }

  // Memories: by subject, by body, by source — and by the jobs above.
  const memoryRows =
    anchor.kind === 'contact'
      ? await db.query<{ memory_id: string }>(
          `SELECT memory_id FROM memories
            WHERE business_id = $1
              AND (subject_key = $2
                OR body::text ILIKE $3 ESCAPE '\\'
                OR coalesce(source_ref, '') ILIKE $3 ESCAPE '\\'
                OR written_by_job = ANY ($4))`,
          [businessId, anchor.identifier, `%${likeLiteral(anchor.identifier)}%`, [...jobIds]],
        )
      : await db.query<{ memory_id: string }>(
          'SELECT memory_id FROM memories WHERE business_id = $1 AND written_by_job = ANY ($2)',
          [businessId, [...jobIds]],
        );

  // Kept items drop out of the plan and into the exclusions, never silently.
  const keptDocuments = await keptIds('document', { businessId, db });
  const keptMemories = await keptIds('memory', { businessId, db });
  const keptJobs = await keptIds('job', { businessId, db });

  const excluded: KeptExclusion[] = [];
  const { rows: keptRows } = await db.query<{
    item_kind: string;
    item_id: string;
    kept_at: Date;
    note: string | null;
  }>('SELECT item_kind, item_id, kept_at, note FROM kept_items WHERE business_id = $1', [
    businessId,
  ]);

  const keepInfo = new Map(keptRows.map((row) => [`${row.item_kind}:${row.item_id}`, row]));
  const noteFor = (kind: KeptItemKind, id: string): void => {
    const row = keepInfo.get(`${kind}:${id}`);
    if (row === undefined) return;
    excluded.push({
      itemKind: kind,
      itemId: id,
      keptAt: row.kept_at.toISOString(),
      note: row.note,
    });
  };

  const memoryIds: string[] = [];
  for (const row of memoryRows.rows) {
    if (keptMemories.has(row.memory_id)) noteFor('memory', row.memory_id);
    else memoryIds.push(row.memory_id);
  }

  const keptDocumentList = [...documentIds].filter((id) => keptDocuments.has(id));
  for (const id of keptDocumentList) noteFor('document', id);
  const documentList = [...documentIds].filter((id) => !keptDocuments.has(id));

  const keptJobList = [...jobIds].filter((id) => keptJobs.has(id));
  for (const id of keptJobList) noteFor('job', id);
  const jobList = [...jobIds].filter((id) => !keptJobs.has(id));

  // Refusals.
  const refusals: ErasureRefusal[] = [];

  if (jobList.length > 0) {
    const { rows } = await db.query<{ job_id: string; phase: string }>(
      'SELECT job_id, phase FROM jobs WHERE business_id = $1 AND job_id = ANY ($2) AND phase = ANY ($3)',
      [businessId, jobList, LIVE_PHASES],
    );
    for (const row of rows) {
      refusals.push({
        kind: 'live_job',
        detail: `משימה ${row.job_id} נמצאת ב-${row.phase} ותלויה בפריטים האלה. בטל אותה קודם, או הוצא אותם מהמחיקה.`,
      });
    }
  }

  const filePaths: string[] = [];
  if (documentList.length > 0) {
    const { rows } = await db.query<{ document_id: string; stored_path: string }>(
      'SELECT document_id, stored_path FROM documents WHERE business_id = $1 AND document_id = ANY ($2)',
      [businessId, documentList],
    );
    for (const row of rows) filePaths.push(row.stored_path);

    const signed = await db.query<{ document_id: string; signed_by: string }>(
      'SELECT document_id, signed_by FROM signatures WHERE business_id = $1 AND document_id = ANY ($2)',
      [businessId, documentList],
    );
    for (const row of signed.rows) {
      refusals.push({
        kind: 'signed_document',
        detail: `חתמת על המסמך ${row.document_id}. מחיקתו תמחק את הראיה שחתמת.`,
      });
    }
  }

  const items = await countItems(db, businessId, jobList, documentList, memoryIds);

  return {
    anchor,
    jobIds: jobList,
    documentIds: documentList,
    memoryIds,
    filePaths,
    items,
    excluded,
    refusals,
  };
}

/**
 * The preview's numbers, and the executor's work list.
 *
 * `delete` versus `scrub` follows the rule in spec §5.1.1: a row whose whole
 * existence is the content goes; a row that merely carries a content field
 * stays and is emptied, so audit rows keep pointing at jobs that exist.
 */
async function countItems(
  db: Queryable,
  businessId: string,
  jobIds: string[],
  documentIds: string[],
  memoryIds: string[],
): Promise<ErasureItem[]> {
  const one = async (
    table: string,
    action: 'delete' | 'scrub',
    sql: string,
    params: unknown[],
  ): Promise<ErasureItem> => {
    const { rows } = await db.query<{ n: string }>(sql, params);
    return { table, action, count: Number(rows[0]?.n ?? '0') };
  };

  return [
    await one('memories', 'delete', 'SELECT count(*)::text AS n FROM memories WHERE business_id=$1 AND memory_id = ANY($2)', [businessId, memoryIds]),
    await one('documents', 'delete', 'SELECT count(*)::text AS n FROM documents WHERE business_id=$1 AND document_id = ANY($2)', [businessId, documentIds]),
    await one('document_artifacts', 'delete', 'SELECT count(*)::text AS n FROM document_artifacts WHERE business_id=$1 AND document_id = ANY($2)', [businessId, documentIds]),
    await one('document_readings', 'delete', 'SELECT count(*)::text AS n FROM document_readings WHERE business_id=$1 AND document_id = ANY($2)', [businessId, documentIds]),
    await one('proposals', 'delete', 'SELECT count(*)::text AS n FROM proposals WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]),
    await one('approval_requests', 'delete', 'SELECT count(*)::text AS n FROM approval_requests WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]),
    await one('boss_instructions', 'delete', 'SELECT count(*)::text AS n FROM boss_instructions WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]),
    await one('job_plans', 'delete', 'SELECT count(*)::text AS n FROM job_plans WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]),
    await one('job_authorizations', 'delete', 'SELECT count(*)::text AS n FROM job_authorizations WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]),
    await one('jobs', 'scrub', 'SELECT count(*)::text AS n FROM jobs WHERE business_id=$1 AND job_id = ANY($2) AND title IS NOT NULL', [businessId, jobIds]),
    await one('job_steps', 'scrub', 'SELECT count(*)::text AS n FROM job_steps WHERE job_id = ANY($1)', [jobIds]),
    await one('job_step_results', 'scrub', 'SELECT count(*)::text AS n FROM job_step_results WHERE business_id=$1 AND job_id = ANY($2) AND external_id IS NOT NULL', [businessId, jobIds]),
  ];
}

/**
 * Carrying out an erasure the owner confirmed.
 *
 * Deletes exactly what the plan lists and resolves nothing of its own. A row
 * the plan did not name is not deleted, however right it might have been to
 * delete it — that is what makes the preview the owner approved the truth
 * about what happened (spec §4.4).
 *
 * **Order: the database first, then the files.** A file deletion cannot be
 * rolled back and is not part of the transaction. If the file goes first and
 * the transaction then fails, a document row points at nothing. If the
 * database goes first and a file deletion fails, an orphan file nobody
 * references survives on disk — reported loudly, and cleanable. Of the two
 * failures only the second can be repaired (spec §7).
 */
import { unlink } from 'node:fs/promises';
import { config } from '../config.js';
import { getPool } from '../db/pool.js';
import { appendAudit } from '../audit/log.js';
import { canonicalHash } from '../util/canonical.js';
import type { ErasureItem, ErasurePlan } from './erasure-plan.js';

/** Thrown when a plan carrying a refusal is handed to the executor. */
export class ErasureRefusedError extends Error {}

export interface ErasureOutcome {
  deleted: ErasureItem[];
  filesRemoved: number;
  /** Paths the database no longer references and the disk still holds. */
  filesFailed: string[];
}

export async function executeErasure(
  plan: ErasurePlan,
  options: { businessId?: string } = {},
): Promise<ErasureOutcome> {
  const businessId = options.businessId ?? config.businessId;

  if (plan.refusals.length > 0) {
    throw new ErasureRefusedError(plan.refusals.map((r) => r.detail).join(' · '));
  }

  const { jobIds, documentIds, memoryIds } = plan;
  const client = await getPool().connect();
  try {
    await client.query('BEGIN');

    // Deleted: rows whose whole existence is the content.
    await client.query('DELETE FROM memories WHERE business_id=$1 AND memory_id = ANY($2)', [businessId, memoryIds]);
    await client.query('DELETE FROM document_artifacts WHERE business_id=$1 AND document_id = ANY($2)', [businessId, documentIds]);
    await client.query('DELETE FROM document_readings WHERE business_id=$1 AND document_id = ANY($2)', [businessId, documentIds]);
    await client.query('DELETE FROM proposals WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);
    await client.query('DELETE FROM approval_requests WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);
    await client.query('DELETE FROM boss_instructions WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);
    await client.query('DELETE FROM job_plans WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);
    await client.query('DELETE FROM job_authorizations WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);
    await client.query('DELETE FROM documents WHERE business_id=$1 AND document_id = ANY($2)', [businessId, documentIds]);

    // Scrubbed: rows that carry a content field and must keep existing, so
    // audit rows go on pointing at jobs that are really there.
    await client.query('UPDATE jobs SET title = NULL WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);
    await client.query(`UPDATE job_steps SET reason = 'נמחק בהוראת הבעלים' WHERE job_id = ANY($1)`, [jobIds]);
    await client.query('UPDATE job_step_results SET external_id = NULL WHERE business_id=$1 AND job_id = ANY($2)', [businessId, jobIds]);

    await client.query('COMMIT');
  } catch (err) {
    await client.query('ROLLBACK');
    throw err;
  } finally {
    client.release();
  }

  // Only now the disk.
  let filesRemoved = 0;
  const filesFailed: string[] = [];
  for (const path of plan.filePaths) {
    try {
      await unlink(path);
      filesRemoved += 1;
    } catch (err) {
      // A file that was already gone is not a failure: the goal was that it
      // not be there, and it is not.
      if ((err as NodeJS.ErrnoException).code === 'ENOENT') continue;
      filesFailed.push(path);
    }
  }

  const total = plan.items.reduce((sum, item) => sum + item.count, 0);
  await appendAudit(
    {
      actor: 'human',
      kind: 'erasure',
      charterVersion: 'n/a',
      provenance: 'boss',
      // Counts only. The anchor's KIND is safe to record; its value is the
      // identity the owner asked to remove, and naming it here would defeat
      // the whole operation.
      inputHash: canonicalHash({ anchorKind: plan.anchor.kind, total }),
      artifacts: [],
      costMinor: null,
      tokens: null,
      reason:
        `מחיקה בהוראת הבעלים · עוגן מסוג ${plan.anchor.kind} · ` +
        `${total} פריטים · ${plan.filePaths.length} קבצים · ` +
        `${plan.excluded.length} נשמרו לפי הוראה קודמת` +
        (filesFailed.length > 0 ? ` · ${filesFailed.length} קבצים לא נמחקו מהדיסק` : ''),
    },
    { businessId },
  );

  return { deleted: plan.items, filesRemoved, filesFailed };
}

/**
 * Distinctive enough that a match anywhere is this test's doing and not a
 * coincidence, and shaped like an address so every place that stores one

const PROBE = 'zz-erase-probe-7f3a@nowhere.example';

/**
 * The three tables an erasure deliberately leaves alone (spec §5.2). Named,
 * so the scan below is a positive control: everything not on this list must
 * come back clean, including a table added next year.
 */
const SURVIVES: readonly string[] = ['audit_log', 'spend_ledger', 'signatures'];

describe('what an erasure leaves behind', () => {
  beforeEach(async () => {
    await resetDatabase();
  });

  afterAll(async () => {
    await closePool();
  });

  /**
   * The test that matters, and it is the opposite of the obvious one.
   *
   * "Erase, then check the row is gone" only checks the places whoever wrote
   * it thought of. The dangerous gap is the place nobody thought of — and
   * this project has already been surprised twice by exactly that
   * (`job_plans` holds the message body; `job_authorizations` holds the typed
   * recipients).
   *
   * So: seed the probe everywhere, erase, then read the column list out of
   * `information_schema` — not out of a list written here — and demand zero
   * matches. A table added a year from now is scanned automatically, and
   * somebody who adds a store and forgets to wire erasure into it turns this
   * red without having to remember this file exists.
   */
  it('leaves the probe in no text or JSON column of any table, anywhere', async () => {
    const bundle = await installCharter(buildCharter({ version: 'probe' }), { businessId: BUSINESS });
    const job = await createJob({
      charterVersion: bundle.charterVersion,
      provenance: 'boss',
      businessId: BUSINESS,
      title: `מייל אל ${PROBE}`,
    });
    const db = getPool();

    await db.query(
      `INSERT INTO job_authorizations (business_id, job_id, action_class, recipients)
       VALUES ($1, $2, 'email.reply', ARRAY[$3])`,
      [BUSINESS, job.jobId, PROBE],
    );
    await db.query(
      `INSERT INTO job_plans (business_id, job_id, plan_hash, plan)
       VALUES ($1, $2, 'hp', $3::jsonb)`,
      [BUSINESS, job.jobId, JSON.stringify({ steps: [{ input: { to: [PROBE], body: 'שלום' } }] })],
    );
    await db.query(
      `INSERT INTO boss_instructions (instruction_id, business_id, job_id, text)
       VALUES ('INS-probe', $1, $2, $3)`,
      [BUSINESS, job.jobId, `תשלחי אל ${PROBE}`],
    );
    await writeMemory(
      { jobId: job.jobId, kind: 'entity', subjectKey: PROBE, body: { email: PROBE } },
      { businessId: BUSINESS },
    );

    const plan = await buildErasurePlan({ kind: 'contact', identifier: PROBE }, { businessId: BUSINESS });
    await executeErasure(plan, { businessId: BUSINESS });

    const { rows: columns } = await db.query<{ table_name: string; column_name: string }>(
      `SELECT c.table_name, c.column_name
         FROM information_schema.columns c
         JOIN information_schema.tables t USING (table_schema, table_name)
        WHERE t.table_schema = 'public' AND t.table_type = 'BASE TABLE'
          AND c.data_type IN ('text', 'jsonb', 'json', 'ARRAY')`,
    );

    const found: string[] = [];
    for (const column of columns) {
      if (SURVIVES.includes(column.table_name)) continue;
      const { rows } = await db.query<{ n: string }>(
        `SELECT count(*)::text AS n FROM "${column.table_name}"
          WHERE "${column.column_name}"::text LIKE $1`,
        [`%${PROBE}%`],
      );
      if (Number(rows[0]?.n ?? '0') > 0) {
        found.push(`${column.table_name}.${column.column_name}`);
      }
    }

    expect(found).toEqual([]);
  });

  /**
   * And the other direction, without which the scan above is satisfied
   * perfectly by an erasure that deletes the whole database.
   */
  it('leaves a second contact entirely intact', async () => {
    const bundle = await installCharter(buildCharter({ version: 'two' }), { businessId: BUSINESS });
    const mk = async (identifier: string, title: string): Promise<string> => {
      const job = await createJob({
        charterVersion: bundle.charterVersion,
        provenance: 'boss',
        businessId: BUSINESS,
        title,
      });
      await getPool().query(
        `INSERT INTO job_authorizations (business_id, job_id, action_class, recipients)
         VALUES ($1, $2, 'email.reply', ARRAY[$3])`,
        [BUSINESS, job.jobId, identifier],
      );
      await writeMemory(
        { jobId: job.jobId, kind: 'entity', subjectKey: identifier, body: { email: identifier } },
        { businessId: BUSINESS },
      );
      return job.jobId;
    };

    await mk(PROBE, 'probe');
    const keptJob = await mk('keeper@nowhere.example', 'keeper');

    const plan = await buildErasurePlan({ kind: 'contact', identifier: PROBE }, { businessId: BUSINESS });
    await executeErasure(plan, { businessId: BUSINESS });

    const memories = await getPool().query<{ subject_key: string }>(
      'SELECT subject_key FROM memories WHERE business_id=$1',
      [BUSINESS],
    );
    expect(memories.rows.map((r) => r.subject_key)).toEqual(['keeper@nowhere.example']);

    const auth = await getPool().query('SELECT 1 FROM job_authorizations WHERE job_id=$1', [keptJob]);
    expect(auth.rows).toHaveLength(1);
  });

  /**
   * Erasure must never become something a plan can invoke: an injected
   * document would say "forget what you found out about me" and the evidence
   * would go (spec §3). Checked by reading the source, because the property
   * is about who may import it, not about what it does when called.
   */
  it('is imported by nothing outside governance and the dashboard', async () => {
    const roots = ['src/orchestrator', 'src/sdk', 'src/policy', 'src/documents', 'src/charter'];
    const offenders: string[] = [];

    const walk = async (dir: string): Promise<void> => {
      let entries;
      try {
        entries = await readdir(dir, { withFileTypes: true });
      } catch {
        return;
      }
      for (const entry of entries) {
        const path = join(dir, entry.name);
        if (entry.isDirectory()) {
          await walk(path);
          continue;
        }
        if (!entry.name.endsWith('.ts') || entry.name.endsWith('.test.ts')) continue;
        const source = await readFile(path, 'utf8');
        if (source.includes('erasure.js') || source.includes('executeErasure')) {
          offenders.push(path);
        }
      }
    };

    for (const root of roots) await walk(root);
    expect(offenders).toEqual([]);
  });

  it('names erasure in no tool table and no agent allowlist', async () => {
    const classify = await readFile('src/policy/classify.ts', 'utf8');
    const capabilities = await readFile('src/charter/capabilities.ts', 'utf8');
    for (const forbidden of ['memory.forget', 'erase', 'erasure']) {
      expect(classify.includes(`'${forbidden}'`), `classify.ts names ${forbidden}`).toBe(false);
      expect(capabilities.includes(`'${forbidden}'`), `capabilities.ts names ${forbidden}`).toBe(false);
    }
  });
});

```ts
export interface ErasureViewModel {
  csrf: string;
  anchorLabel: string;
  plan: ErasurePlan;
}

/** Hebrew names for the tables, so the owner reads what they are losing. */
const TABLE_LABELS: Record<string, string> = {
  memories: 'זיכרונות',
  documents: 'מסמכים',
  document_artifacts: 'טקסט שחולץ ממסמכים',
  document_readings: 'סיכומים',
  proposals: 'הצעות',
  approval_requests: 'כרטיסי אישור',
  boss_instructions: 'לשון הוראות',
  job_plans: 'תוכניות',
  job_authorizations: 'הרשאות',
  jobs: 'כותרות משימה',
  job_steps: 'שורות מעבר',
  job_step_results: 'מזהי הודעה מהספק',
};

export function renderErasure(model: ErasureViewModel): string {
  const { plan } = model;
  const rows = plan.items
    .filter((item) => item.count > 0)
    .map(
      (item) =>
        `<tr><td>${esc(TABLE_LABELS[item.table] ?? item.table)}</td>` +
        `<td>${item.count}</td>` +
        `<td>${item.action === 'delete' ? 'יימחק' : 'ינוקה מתוכן'}</td></tr>`,
    )
    .join('');

  const refusals = plan.refusals
    .map((r) => `<p class="refusal">${esc(r.detail)}</p>`)
    .join('');

  const kept = plan.excluded
    .map(
      (k) =>
        `<li>${escLabel(k.itemId)} — נשמר ב-${esc(k.keptAt.slice(0, 10))}` +
        (k.note === null ? '' : ` (${escLabel(k.note)})`) +
        ` <form method="post" action="/erase/keep"><input type="hidden" name="csrf" value="${esc(model.csrf)}">` +
        `<input type="hidden" name="revoke" value="1">` +
        `<input type="hidden" name="kind" value="${esc(k.itemKind)}">` +
        `<input type="hidden" name="itemId" value="${esc(k.itemId)}">` +
        `<button type="submit">בטל שמירה</button></form></li>`,
    )
    .join('');

  const confirm =
    plan.refusals.length > 0
      ? ''
      : `<form method="post" action="/erase/confirm">
           <input type="hidden" name="csrf" value="${esc(model.csrf)}">
           <input type="hidden" name="anchor" value="${esc(JSON.stringify(plan.anchor))}">
           <button type="submit" class="danger">מחק לצמיתות</button>
         </form>`;

  return page(
    'מחיקה',
    `<h1>מחיקה — ${escLabel(model.anchorLabel)}</h1>
     ${refusals}
     <table><tr><th>מה</th><th>כמה</th><th>מה יקרה</th></tr>${rows}</table>
     ${plan.filePaths.length > 0 ? `<p>${plan.filePaths.length} קבצים יימחקו מהדיסק.</p>` : ''}
     ${kept === '' ? '' : `<h2>יישמרו לפי הוראתך</h2><ul>${kept}</ul>`}
     <p class="note">מסלול הביקורת יישמר — הוא אינו מחזיק שמות, כתובות או תוכן.</p>
     ${confirm}
     <form method="get" action="/"><button type="submit">ביטול</button></form>`,
  );
}
```
